## 浏览器

`node apps/web/e2e/walkthrough.mjs` 在 API `127.0.0.1:8000` 和 Vite `127.0.0.1:5173` 都已启动时退出码为 0，并写出 19 张截图。过程中发现并修复的问题：

- 采集者登录后被通配重定向送到总览。已改为按角色进入 `/app/mine`。
- 仿真自动核验使用 `system` 角色，但状态机不允许 `submitted → verified`。已把 `system` 加入该迁移。否则单步在有到期任务时返回 409。
- 移动端导航在收缩时把汉字竖排拆开。链接改为不换行并可横向滚动。

## 算法正确性里已经检查的情形

- 概率和不合法会被拒绝。
- 决策上下文不包含未来真值和未来轨迹。
- 移动拟合的可见上界不包括目标时刻之后。
- 预算用尽后不再分配。
- 过期迁移在窗口未结束时被拒绝。
- 重复提交同一已完成任务返回 409。
- 提交没有测量值返回 422。

## 尚未用自动化钉死的情形

“所有参与者都不可达”和“预算为零”在分配函数里会得到空列表，但没有单独命名的测试函数。行为由分数下限和预算判断实现。这是测试缺口，不是已经观察到的错误分配。
