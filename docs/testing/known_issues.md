# 已知问题

1. Docker 守护进程不存在，Compose 文件没有跑通。
2. 完整 YJMob100K、GeoLife、NoiseCapture 没有下载，因此没有真实数据上的误差表，也没有真实时空联合实验。
3. MU-PSA 不是所有预算上因果 MAE 最低的方法。见主实验表。
4. 去掉覆盖项或重规划，在 complex、预算 24 的消融里平均 MAE 略好于完整模型。
5. 最近参与者基线成功次数低，因为它用当前距离给下一时间片打分。
6. IDW、树间标准差和固定核 GP 的区间没有做独立校准。GP 在主探测里区间很宽。
7. LinUCB 训练奖励使用仿真误差下降。公平比较只覆盖 regular、预算 24、五个世界。训练回报不单调。
8. 没有 Gymnasium、PPO 或 Stable-Baselines3。
9. 数据库用 `create_all`，没有 Alembic 修订链。
10. 顶栏每 4 秒拉一次总览，单步之后可能暂时显示旧时钟。
11. 演示 JWT 密钥写在仓库示例里，不能用于生产。
12. 前端设计技能的 `npx skills add` 没有执行记录。
13. “预算为零”和“全员不可达”没有单独的测试函数名。
14. FastAPI TestClient 提示安装 `httpx2`。测试仍然通过。
15. 采集者仿真采样在人不在任务网格上时会返回错误。这是预期约束，不是地图故障。
