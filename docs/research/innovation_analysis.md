# 创新分析

## 三个候选方案

方案 A：用移动预测做预算内的任务分配，价值只看覆盖或距离。

方案 B：只按噪声预测的不确定性选择采样点，参与者只要当前距离可接受就分配。

方案 C：把下一时间片的到达概率、接受概率、设备质量、启发式信息价值和成本放进同一次约束匹配，执行后再用新观测更新。

本项目实现了方案 C，内部名称是 Mobility- and Uncertainty-Aware Predictive Sampling and Assignment（MU-PSA）。同时也实现了 A/B 所对应的基线：最近可行参与者、贪心价值、只按不确定性，以及随机和最小成本匹配。方案 C 没有被预设为优胜者。

## 和文献的实质差别

已核实文献已经分别讨论了稀疏选点、移动可预测性、任务成本和序贯分配。MU-PSA 的差别只是把这些因素写成了下面这个**启发式**分数，并放进一个可复现实验：

```
P(success) = P(reach) * P(accept) * quality
score = P(success) * Value - 0.35 * cost
Value = 1.0 * unc_norm + 0.65 * (coverage_gap + 0.5 * isolation)
        + 0.25 * temporal_gap - 0.8 * duplicate
```

到达、接受和执行成功是分开的量。代码没有把“会经过格子”当成“会接受任务”。

这个分数不是互信息，也没有子模近似比。不确定性来自 IDW 的距离和邻居分歧、随机森林树间标准差，或固定核高斯过程的预测标准差。报告不把它们称为已校准置信区间。

## 实验是否支持“更好”

主实验是 14×14 网格、每天 24 个时间片、16 名人类和 4 台机器、5 个种子、regular 与 complex 两个场景。因果 MAE 使用每个评估时间片上、只用当时及以前观测的 IDW，对干净仿真场取绝对误差。

在 regular、预算 16 时，MU-PSA 的平均因果 MAE 为 5.854，是该预算六种主方法里最低的。预算 8 时不确定性采样更低（5.576 对 7.520）。预算 24 和 36 时最小成本匹配更低（4.939 和 5.147，对 MU-PSA 的 6.232 和 6.000）。MU-PSA 的平均到达概率大约 0.93–0.96，唯一格子覆盖率更高，但误差不总是更低。

complex 场景的消融（预算 24，5 个种子）里，去掉移动预测或去掉不确定性会使平均 MAE 变差（7.748 和 8.149，完整模型 6.816）。去掉覆盖项或去掉重规划反而略好（6.576 和 6.319）。因此不能写“完整模型全面优于消融”。

最近参与者基线的成功次数很低。它用**当前**距离给 **下一** 时间片的任务打分，而人的下一位置不一定还在当前邻域。这是基线定义带来的结果，报告里必须说明，不能把它写成“任何距离方法都无效”。最小成本匹配把“当前距离在半径内或到达概率至少 0.22”当作可行，再最小化成本。它不是完全不看移动。

LinUCB 在单独的 5 个种子、regular、预算 24 上，平均因果 MAE 为 5.056，低于同一次运行里的不确定性采样、最小成本匹配和 MU-PSA。这只是一个场景和一个预算，而且训练奖励使用了仿真误差下降。上下文不含真值。训练曲线 12 次的回报没有单调上升。不能把这一次结果写成策略普遍更优。

## 不能声称的话

- 不能声称学术新颖性已经由文献空白证明。检索里已经有稀疏采样、移动预测和强化学习分配，其中还有一条被撤回的移动预测分配预印本。
- 不能声称真实城市联合实验。YJMob 虚拟网格、GeoLife 经纬度和 NoiseCapture 点没有在时间和空间上对齐。
- 不能声称强化学习达到了 PPO 的实现。环境不是 Gymnasium。
