# 算法假设

标签：Hypothesis。

假设：在到达概率差异较大时，用单格方差下降 `v²/(v+r)` 乘上到达概率和接受概率，会比只按当前位置选最近的人，得到更低的 `mae_available_at_t`。

这个假设只覆盖已经实现的式子。它不包含邻居格子的协方差更新。

可被反驳的情况，也是这次实验里要保留的结果：

- 如果某个预算上 `eer_reach` 的平均 MAE 不低于 `reach_random`、`min_cost` 或 `nearest`，就不能说它在该预算上赢了。
- 如果去掉接受概率之后 MAE 更低，接受概率这一项在该切片上没有帮助。
- 如果去掉成本之后分数不变，0.35 的成本项在该切片上没有改变选择。

权重没有在看完结果之后再调。
